# PuppyMart World — Swift (stage 1)

SwiftUI + SceneKit. Original art and characters. Needs Xcode 15 or later, iOS 16+.

## Set up in Xcode
1. Xcode → File → New → Project → iOS → **App**. Name: `PuppyMartWorld`, Interface: SwiftUI, Language: Swift.
2. In the project navigator delete the generated `ContentView.swift` and `PuppyMartWorldApp.swift`.
3. Drag the four `.swift` files from this folder into the project (tick "Copy items if needed" and your app target).
4. Pick an iPhone simulator or your iPhone (cable, Developer Mode on) and press Run (Cmd+R).

## What's in stage 1
- 3D island with pines, round trees, bushes, lamp and sign
- Original avatar, joystick movement, camera rotate buttons
- 6 dogs hiding in bushes: ears twitch out of the bush, the dog pops out as you approach
- Catch mini-game: moving marker, running/jumping green zone, 3 tries, rarity-based difficulty
- Coins and caught counter
